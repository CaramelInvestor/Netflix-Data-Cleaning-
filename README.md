# Netflix-Data-Cleaning-
Prepare and organize the Netflix Dataset for business analytics and reporting

Task Workflow
Step 1: Import the dataset using Python and Pandas.
Step 2: Identify and handle missing values.
Step 3: Remove duplicate records and formatting
inconsistencies.
Step 4: Standardize columns such as Country, Rating, and
Type.
Step 5: Export the cleaned dataset for analysis.
